# Examples ritz1 (and ritz1_selfhosted) cannot yet compile, one example key
# per line.  Anything NOT listed that fails to compile fails the suite.
#
# IMPORTANT: this list covers *compile* failures only.  A behavioural
# difference — stdout or exit-code mismatch against the ritz0 baseline — is
# never allowlisted.  That would be a miscompile, and the whole point of
# stages 3 and 4 is to make miscompiles impossible to ignore.
#
# ritz1_selfhosted deliberately shares this file.  If ritz1 and its
# self-compiled twin ever disagree, that is a self-hosting fixed-point bug and
# must go red rather than be recorded here.
#
# That last sentence used to be a request.  It is now enforced: Stage 5 of
# regression.sh compares the two accepted sets directly and reads no allowlist
# at all, so nothing you write in this file can hide a ritz1 vs
# ritz1_selfhosted divergence.  Adding an entry here to turn a red Stage 5
# green does not work by construction — the entry is invisible to that check.
# An allowlist may say "this program is known not to compile"; it may never say
# "these two compilers may disagree."
#
# THIS LIST IS CALIBRATED AGAINST clang/LLVM 21.  It has to be calibrated
# against something, because clang is what decides "cannot compile", and
# different LLVM versions disagree.  See projects/ritz/docs/TOOLCHAIN.md; CI
# pins the version (.github/actions/install-toolchain) so that this file means
# the same thing everywhere.  Re-seeding it against an unpinned clang will
# silently produce a list that is wrong on every other machine.
#
# Seeded 2026-09-02: stage 3 and stage 4 each 42 passed / 26 failed, with the
# two failure sets byte-identical.  These are the 26.
#
# 2026-09-02 (AGAST #1308): re-verified entry by entry against clang 21, and
# the original header note — "every entry is a feature ritz1 has not caught up
# to ritz0 on" — turned out to be false for eight of them.  Those eight are
# not missing features.  ritz1 compiles them fine and emits IR that violates
# SSA dominance; LLVM 21 rejects it and the older clang on the CI runner
# accepted it, which is why this list read as 26 failures locally and 18 in
# CI.  They are split out below because the distinction changes what you do
# about them: compiler debt waits for a feature, a dominance violation is a
# codegen bug with a ticket.
#
# The list should shrink.  Nothing is removed from it without a run that shows
# the example compiling; nothing is added to it without knowing why it fails.
