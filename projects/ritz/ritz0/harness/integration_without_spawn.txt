# `integration`-marked ritz0 tests that start no process (AGAST #4627).
#
# spawn_guard fails a passing `integration` test that started no process, ran
# no ritz0 in-process, took no batched answer and used no fixture that did:
# the mark keeps it out of `-m inproc`, so `make tools-ratchets` never runs
# it.  These functions are let off.  One entry per test function
# (`path::[Class::]name`, no parameters), relative to ritz0/.
# tests/test_integration_without_spawn.py holds each entry to an existing,
# `integration`-marked test function.
#
# Only remove entries.  Measured with
#   RITZ_TEST_NOSPAWN_LOG=/tmp/nospawn.log python3 -m pytest -p xdist -n 6 ...
# which reports an offender instead of failing it.

# Parametrized functions where only some parameters spawn (a row that
# returns early, or a variant compiled in-process): the mark is the
# function's, so it stays.
