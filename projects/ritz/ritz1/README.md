# ritz1 - The Ritz Self-Hosting Compiler

The Ritz compiler written in Ritz. ritz0 builds it; it then builds itself.

## Status

Builds with ritz0 into a native Linux binary that compiles Ritz to LLVM IR,
and builds itself (`ritz1_selfhosted`). The module map is
[ARCHITECTURE.md](ARCHITECTURE.md); sizes and the import graph are
`make -C projects/ritz arch-report`.

**Capabilities:**
- Direct-coded lexer (partly generated by ritzgen) with indentation tracking
- Recursive descent parser (generated from `grammars/ritz1.grammar`)
- Generic type-arg inference and monomorphization
- A checking phase (Sema) before code generation
- LLVM IR code generation with SSA form
- Recursive import resolution via `RITZ_PATH`
- Separate compilation (1 `.ritz` file -> 1 `.ll` file) with a per-file cache

## Build

```bash
# Build ritz1 using ritz0
make ritz1
```

## Usage

```bash
./build/ritz1 <input.ritz> -o <output.ll>
./build/ritz1 <input.ritz> -o <output.ll> -I <ritz_path>
```

## Bootstrap

ritz1 can compile itself:

```bash
make bootstrap   # builds ritz1_selfhosted using ritz1
make verify      # tests both binaries produce correct output
```
